# دفترچهٔ علمی من 📓

دفترچهٔ شخصی یادگیری دندان‌پزشکی — کاملاً فارسی و راست‌به‌چپ.

**فلسفه:** این سایت ابزار یادگیری است، نه تبلیغ. شواهد علمی از برداشت شخصی
جدا می‌شوند؛ نیمه‌کاره‌بودن و پرسیدن مجاز است؛ تغییر نظرات ثبت می‌شود.

این راهنما برای روزهای عادی نوشته شده: هر کاری که لازم شود، همین‌جا هست.

---

## ۱) اجرای سایت روی کامپیوتر

1. پنجرهٔ Command Prompt باز کنید (کلید Windows → تایپ `cmd` → Enter)
2. دستورهای زیر را بزنید:

   ```
   cd "C:\تغییر رویه\سایت"
   npm run dev
   ```

3. در مرورگر: **http://localhost:4321**
4. توقف: `Ctrl+C`

> اگر Node.js تازه نصب شده و `npm` شناخته نشد، پنجرهٔ cmd را ببندید و دوباره باز کنید.

## ۳) نوشتن یادداشت جدید

یک فایل جدید در پوشهٔ بخش مربوطه بسازید (نام فایل انگلیسی، متن فارسی).
ساده‌ترین راه: کپی یکی از فایل‌های موجود و عوض‌کردن متن.

قالب هر فایل:

```
---
title: عنوان
description: خلاصهٔ یک‌خطی
pubDate: 2026-11-07
kind: question      ← اختیاری: reading-note / question / lesson / reflection / idea / article
paper: (نقل کامل مقالهٔ مرجع)   ← برای یادداشت مطالعه
---

متن...
```

### قانون‌های مهم

- بخش بالای فایل (بین دو خط `---`) باید **همیشه اولین چیز فایل** باشد.
- اگر عنوان علامت «:» دارد، داخل گیومه بگذارید: `title: 'حساسیت دندان: چه کنیم؟'`
- `pubDate` در سایت به تقویم شمسی نمایش داده می‌شود.
- منتشر نشدن موقت: `draft: true`
- نیم‌فاصله با `Shift+Space`: «دندان‌پزشکی» ✓

### بلوک‌های «صداقت» — مهم‌ترین ابزار این دفترچه

داخل متن، هر ادعا را در بلوک مخصوص خودش بنویسید:

```
:::evidence
یافتهٔ مستند از مقالهٔ منتشرشده، با ارجاع دقیق.
:::

:::interpretation
برداشت و تفسیر شخصی من از شواهد.
:::

:::experience
تجربهٔ بالینی خودم.
:::

:::hypothesis
فرضیه یا پرسش بررسی‌نشده — نه ادعا.
:::
```

هر بلوک در سایت با برچسب و ظاهر مخصوص خودش نمایش داده می‌شود.

### به‌روزشدن یک یادداشت (وقتی نظر عوض شد)

بخش بالای فایل را کامل کنید:

```
updated: 2026-12-01
changelog:
  - date: 2026-12-01
    note: بعد از خواندن مقالهٔ X، برداشتم از Y عوض شد.
```

خط git هم تاریخچهٔ کامل هر تغییر را نگه می‌دارد: `git add .` و بعد
`git commit -m "توضیح تغییر"`.

## ۴) ساختار پوشه‌ها

```
سایت/
├── src/
│   ├── config.ts               ← نام سایت، نویسنده، بخش‌ها، انواع یادداشت
│   ├── styles/global.css       ← رنگ‌ها و تایپوگرافی (بخش :root)
│   ├── lib/remark-blocks.mjs   ← پلاگین بلوک‌های :::evidence و…
│   ├── content.config.ts       ← ساختار فیلدهای یادداشت
│   ├── content/                ← محتوا (چهار پوشه، طبق جدول بالا)
│   ├── components/             ← قطعات صفحه‌ها
│   └── pages/                  ← صفحه‌های خود سایت
├── public/                     ← آیکون سایت
├── failsafe/                   ← فایل‌های پژوهشی شما (فقط خواندنی؛ سایت از آن‌ها تغذیه می‌شود)
└── package.json                ← شناسنامهٔ فنی پروژه
```

## ۵) تغییرات رایج

| می‌خواهم… | کجا |
| --- | --- |
| نام سایت را عوض کنم | `src/config.ts` → `name` |
| اطلاعات پروفایل (تلفن، نشانی، اینستاگرام) | `src/config.ts` → `author` |
| رنگ اصلی سایت را عوض کنم | `src/styles/global.css` → `--accent` |
