# مجلهٔ دندان‌پزشکی من 🦷

وب‌سایت شخصی آموزش دندان‌پزشکی — کاملاً فارسی و راست‌به‌چپ، با دو بخش:
**برای بیماران** و **برای دندان‌پزشکان**.

این راهنما برای روزهای عادی نوشته شده: هر کاری که لازم شود، همین‌جا هست.

---

## ۱) اجرای سایت روی کامپیوتر خودتان

1. یک پنجرهٔ Command Prompt یا PowerShell باز کنید (در ویندوز: کلید Windows را بزنید، `cmd` تایپ کنید و Enter).
2. به پوشهٔ پروژه بروید:

   ```
   cd "C:\تغییر رویه\سایت"
   ```

3. دستور زیر را بنویسید و Enter بزنید:

   ```
   npm run dev
   ```

4. در مرورگر این نشانی را باز کنید: **http://localhost:4321**
5. برای متوقف‌کردن سایت، در همان پنجره `Ctrl+C` بزنید.

> هر تغییری در فایل‌ها بدهید، صفحه به‌صورت خودکار در مرورگر تازه می‌شود.

> اگر Node.js تازه نصب شده و دستور `npm` شناخته نشد، پنجرهٔ cmd را ببندید و دوباره باز کنید.

## ۲) نوشتن مقالهٔ جدید (کار روزمرهٔ شما!)

هر مقاله یک فایل متنی ساده است.

### برای مقالهٔ بخش بیماران

فایل جدیدی در این پوشه بسازید:

```
src\content\patients\نام-فایل-انگلیسی.md
```

### برای مقالهٔ بخش دندان‌پزشکان

```
src\content\professionals\نام-فایل-انگلیسی.md
```

### محتوای فایل

ساده‌ترین راه: یکی از مقاله‌های موجود را کپی کنید و متنش را عوض کنید.
قالب هر مقاله این است:

```
---
title: عنوان مقاله
description: خلاصهٔ یک‌خطی که در فهرست‌ها نمایش داده می‌شود
pubDate: 2026-11-06
tags:
  - برچسب اول
  - برچسب دوم
---

متن مقاله از این‌جا شروع می‌شود...

## سرفصل با دو علامت #

### سرفصل فرعی با سه علامت #

- مورد فهرستی
- مورد دیگر

1. مرحلهٔ اول
2. مرحلهٔ دوم

> نقل‌قول یا نکتهٔ مهم

**متن پررنگ**
```

### چند قانون کوچک

- **نام فایل را انگلیسی بنویسید** (مثلاً `root-canal-guide.md`)؛ این نام در نشانی اینترنتی مقاله می‌آید: `localhost:4321/patients/root-canal-guide`
- عنوان و متن داخل فایل فارسی است.
- `pubDate` تاریخ انتشار است و در سایت به تقویم شمسی نشان داده می‌شود.
- **اگر عنوان مقاله علامت «:» دارد، آن را داخل گیومهٔ تکی بگذارید:** `title: 'حساسیت دندان: چرا اتفاق می‌افتد؟'`
- بخش بالای فایل (بین دو خط `---`) باید **همیشه اولین چیز در فایل** باشد؛ هیچ چیزی — حتی کامنت — قبل از آن نگذارید.
- اگر خواستید مقاله فعلاً منتشر نشود، این خط را به بخش بالا اضافه کنید: `draft: true`
- فاصلهٔ فارسی (نیم‌فاصله) با `Shift+Space` در کیبورد فارسی ساخته می‌شود: «دندان‌پزشکی» ✓ / «دندان پزشکی» ✗

## ۳) ساختار پوشه‌ها (برای آشنایی، نه حفظ‌کردن!)

```
سایت/
├── src/
│   ├── config.ts               ← نام سایت و معرفی بخش‌ها (اسم سایت را این‌جا عوض کنید)
│   ├── styles/global.css       ← رنگ‌ها و فونت‌ها (بخش :root بالای فایل)
│   ├── content/
│   │   ├── patients/           ← مقاله‌های «برای بیماران»
│   │   └── professionals/      ← مقاله‌های «برای دندان‌پزشکان»
│   ├── components/             ← قطعات تکراری صفحه‌ها (هدر، فوتر، کارت مقاله)
│   ├── layouts/                ← قالب پایهٔ همهٔ صفحات
│   └── pages/                  ← صفحه‌های خود سایت
├── public/                     ← فایل‌های عمومی (آیکون سایت)
└── package.json                ← شناسنامهٔ فنی پروژه
```

## ۴) تغییرات رایج

| می‌خواهم… | کجا |
| --- | --- |
| نام سایت را عوض کنم | `src/config.ts` → `name` |
| رنگ اصلی سایت را عوض کنم | `src/styles/global.css` → `--accent` در بخش `:root` |
| متن صفحهٔ «درباره» را کامل کنم | `src/pages/about.astro` |
| یک مقالهٔ جدید بنویسم | پوشهٔ `src/content/...` (بخش ۲ همین راهنما) |

## ۵) نسخه‌پشتیبان (git)

این پروژه یک مخزن محلی git دارد؛ تاریخچهٔ تغییرات فقط روی کامپیوتر خودتان
ذخیره می‌شود و هیچ‌جا منتشر نمی‌شود. هر از گاهی که کار خوبی انجام دادید:

```
git add .
git commit -m "توضیح کوتاه تغییرات"
```

## ۶) انتشار در آینده

فعلاً سایت کاملاً خصوصی و محلی است. هر وقت خواستید آن را برای عموم
منتشر کنید، با هم یکی از سرویس‌های رایگان (مثل Netlify یا GitHub Pages)
را راه می‌اندازیم — گفت‌وگوی کوچکی که ساخت خروجی نهایی با این دستور شروع می‌شود:

```
npm run build
```
